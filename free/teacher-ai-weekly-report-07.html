01 · 虚惊一场

DeepSeek 8月6日宣布"大幅涨价"，但涨的是 API，不是你

8月6日 DeepSeek 公告称"计划近期整体上调 API 服务定价，预计涨幅较大"，一时刷屏。需要分清：涨价对象是开发者调用的 API 接口。老师们日常用的网页版和 App 依然完全免费——聊天、传文件、联网搜索全部不限次数。

对老师意味着什么不用换工具，也不用囤额度。DeepSeek 仍是唯一"零成本无限用"的主力大模型，继续放心当备课主力。
02 · 钱包警报

WPS 灵犀 8月3日正式收费，千问办公版同日开启公测

8月3日起 WPS 灵犀专业版正式收费（标准版 48 元/月，5000 灵点），同日阿里千问办公版开启公测（标准版 78 元/月，限时 8 折）。至此国产 AI 办公工具集体迈过免费线：豆包 68 元起、Kimi 49 元起、Trae 45 元起。

对老师意味着什么如果你习惯在 WPS 里直接调 AI 写教案，从这周起会开始撞额度墙。替代路线：先在 DeepSeek / 元宝里生成内容，再粘回 WPS 排版，效果一样、成本为零。

DeepSeek 公告"API 将大幅涨价"——刷屏之外，需要分清两件事

8月6日，DeepSeek 发布公告称"计划近期整体上调 DeepSeek API 服务的定价，预计涨幅较大，请合理安排您的使用，具体方案以正式通知为准"。消息一出迅速刷屏，不少老师在群里问"DeepSeek 要收费了吗"。

需要分清的是：涨价对象是面向开发者的 API 接口，不是网页版和 App。DeepSeek 的商业模式一直是"个人端不设收费门槛，主要靠 API 调用向开发者收费"。当前 API 现行定价中，deepseek-v4-flash 缓存未命中输入 1 元/百万 tokens、输出 2 元/百万 tokens；deepseek-v4-pro 分别为 3 元与 6 元。7月31日 开启公测的 V4-Flash 还引入了峰谷分时计费——工作日 9:00–12:00、14:00–18:00 为高峰时段价格翻倍，夜间、周末、节假日维持平峰低价。

涨价背后是真实的算力压力。据中国信通院数据，2026年一季度国内 AI 算力需求同比增长 417%，有效供给增速仅 128%，供需缺口持续拉大。此前 DeepSeek V4-Flash 曾因访问量过大出现容量不足。

对老师意味着什么：只要你是在 deepseek.com 网页或手机 App 上使用，一切照旧、完全免费、不限次数。不需要换工具，也不需要提前"囤额度"。真正受影响的是用 DeepSeek 接口做二次开发的团队——如果你所在学校的某个 AI 教学系统是接 DeepSeek API 的，可以提前问一下服务商成本会不会传导。
2026年8月3日

同一天两件事：WPS 灵犀专业版正式收费 + 千问办公版开启公测

8月3日，WPS 灵犀专业版正式开始收费，标准版 48 元/月含 5000 灵点；同日，阿里千问办公版开启公测，标准版 78 元/月（限时 8 折）。至此，2026 年 7 月以来国产 AI 办公工具"集体迈过免费线"的过程基本完成。

横向看目前的入门付费门槛：腾讯元宝 0 元、DeepSeek 0 元、TraeWork 45 元/月（首月 9.9）、WPS 灵犀 48 元/月、Kimi 49 元/月、豆包 68 元/月（学生 38）、千问办公 78 元/月。整体定价区间从 0 元一直到 999 元/月，跨度极大。

行业逻辑的转变是清晰的：过去两年为抢市场份额疯狂压低单价甚至大规模免费；进入 2026 年下半年，算力供需紧张、芯片采购成本与运营成本持续走高，"低价换规模"难以为继，整个行业正从"拼低价抢用户"转向"成本可承受前提下的商业化"。

对老师意味着什么：如果你习惯在 WPS 里"选中一段字、右键让 AI 改写"，这周开始会撞额度墙。不必急着付费——把生成环节挪到 DeepSeek 或元宝（都免费无限），把 WPS 退回"排版和打印"的角色，教案质量不会有任何下降。真正值得付费的情形只有一种：你每天要处理大量文档、且时间成本明显高于 48 元/月。
2026年8月上旬

《教育发展"十五五"规划》发布：首次部署"国家数智教育大平台提质升级计划"

近期《教育发展"十五五"规划》公开发布。规划围绕人口结构变化、人工智能变革、人类命运共同体构建三大关键变量前瞻布局，其中把"推进教育数智化变革"列为重点改革任务，并首次部署"国家数智教育大平台提质升级计划"。

具体表述包括：开展"人工智能教育"行动，推动教育理念、培养模式、考试考核、科研范式和治理机制深层次变革；建强用好国家智慧教育公共服务平台；建设国家人工智能（教育）应用中试基地；推进人工智能全学段教育，提升学生人工智能素养。参与规划起草的中国教育科学研究院专家指出，未来 5 年我国教育数字化将从"建平台、配设备"转向"重应用、育新人"。

对老师意味着什么：方向已经明确——AI 应用能力正在从"加分项"变成"基本功"。但这不是坏消息：政策同时明确了"建强用好国家智慧教育公共服务平台"，意味着后续会有更多免费官方资源下发。与其焦虑，不如把国家平台账号先激活、把 AI 工具专区先逛一遍，很多要求其实用免费资源就能达标。
2026年秋季学期起

多地落地：中小学全面开设 AI 通识课，每学年不少于 8 节

地方层面已经开始执行。海口市出台《推进中小学人工智能教育工作方案（2026—2028年）》，遴选 15 所试点校，实施"AI 名师计划"，培养人工智能骨干教师 300 名、领军教师 50 名，从今年秋季学期起全市中小学全面落实每学年不少于 8 节 AI 通识课。同时统筹省级专项资金 1.31 亿元，为 166 所中小学 2221 间教室配齐智慧触控一体机。

江苏宿迁的答复文件也显示：2026 年秋季学期推动全市中小学、职业学校全面开设人工智能通识课；2026 年 8 月底以集团校为单位完成人工智能通识教研联合体建设；遴选 135 所学校试点"师—机—生"协同模式教学；围绕"AI+五育"分两批实施 80 个场景建设项目，总投资约 5700 万元。

对老师意味着什么：如果你所在地区已有类似文件，8 月底前很可能要参加教研联合体活动或示范课打磨。提前准备的最小动作：用 NotebookLM 或 DeepSeek 把当地文件读一遍生成要点清单，再用元宝生成一份 AI 通识课的课件初稿——两个工具都免费，一晚上就能有个像样的底稿。
持续跟踪

Kimi K3 算力告急余波：免费额度仍紧，商用许可落地

7月19日 Kimi 曾公告 K3 发布后 48 小时内用户请求量大幅超出预估、逼近集群承载极限，即日起暂停 C 端新用户订阅，全力推进算力扩容。本周该事件继续发酵：Kimi K3 商用许可落地，被视为"词元分成"打开行业新空间。

会员分层依然清晰：49 元档调不了最新的 Kimi K3 模型；99 元档能用但上下文限制在 256K；只有 199 元以上才解锁完整的 100 万 Token 超长上下文。免费用户每月仅 1 次深度研究、3 次 OK Computer、3 次 PPT 生成。

对老师意味着什么：Kimi 定位已明确转向"重度长文本用户"（程序员看大项目代码、研究员啃论文）。普通中小学老师不建议为它付费——把每月 3 次 PPT 额度留给最重要的公开课，日常课件用元宝免费做。
持续跟踪

豆包：Seedance 2.5 视频生成锁在 200 元以上档位

豆包专业版三档定价延续：68 元/月标准版（额度是免费版 5 倍以上，支持十万字长文档无损解析和 4K 无水印图生成，学生认证 38 元）、200 元/月加强版（额度为标准版 4 倍）、500 元/月高级版（10 倍）。最关键的区别在视频生成——最新接入的 Seedance 2.5 视频模型仅限 200 元和 500 元档位使用，免费用户完全碰不到。B 端 API 定价已于 2026年7月31日 公布。

对老师意味着什么：如果只是日常写文案、出题、基础配图，免费版够用。只有一种情况值得考虑学生价 38 元档：你经常要做高清教学海报或解析十万字级别的长文档。视频生成对绝大多数老师不是刚需。

中美教育 AI 都在转向"教师端"：Claude for Teachers 的启示

过去几年教育 AI 更多围绕学生端展开（答题、辅导）；进入 Agent 时代后，行业开始把注意力转向教师端与学校端，让 AI 进入备课、授课、评价和教学管理流程。美国方面，Anthropic 于 7月14日 推出 Claude for Teachers，免费向经过验证的美国 K-12 教师开放高级功能；其设计思路值得注意——它连接了 Brisk Teaching、Canva Education、Diffit 等一批教育工具，把自己嵌进老师已有的工作环境，并能结合各州课程标准把抽象标准条目转化为具体学习目标、课堂活动、练习方案。国内方面，飞象星球、好未来等也在推动 AI 进入学校和课堂。

对老师意味着什么：Claude for Teachers 目前仅限美国 K-12 教师，国内老师用不上。但它的思路可以直接借鉴——不要指望一个工具搞定一切，而是把 2–3 个工具串成自己的工作流（例如：NotebookLM 读教材 → DeepSeek 写教案 → 元宝出 PPT）。本期 Tab1 的五个场景就是按这个逻辑排的。
