三、手机号绑定核心规则

⚠️ 官方条款：绑定的美国手机号必须属于账号持有人本人，不允许长期使用他人号码；短期应急借用存在显著封号风险。
⚠️ 一条手机号只能绑定 1 个 Prodege 旗下账号（Swagbucks / InboxDollars 共用数据库），不要同一个他人号码绑两个平台。
📞 填写格式：+1区域码+号码，无横线、无括号、无空格（例：+12035551234）。
💡 备选思路：注册阶段尽量不触发手机验证；多数填问卷不强制要手机号，等平台弹窗强制要求时再安排。

四、手机号使用场景与风险

场景 1：临时借用他人实体 SIM（真人亲友，可随时收短信）

✅ 短期应急可完成验证，但有 3 个硬风险：
  1. 信息不匹配：KYC 护照核验时账号姓名（你）≠ 手机号实名（他人）→ 提现驳回、永久冻结。
  2. 控制权不在手：对方可收验证码重置密码、侵占积分。
  3. 二次验证麻烦：平台不定期再推短信核验，联系不上对方则账号受限。

场景 2：线上购买虚拟号 / Google Voice / 接码平台

❌ 强烈不推荐，几乎必翻车：系统能识别 VOIP / 虚拟线路，这类号码大量在黑名单；侥幸注册成功，首次兑换触发复核时 100% 封号、余额清零。

七、风控隔离硬性规则（两账号务必遵守）

1. 浏览器分开：Swagbucks、InboxDollars 用两个独立浏览器，禁同一浏览器来回切换登录；
2. 操作时段错开：间隔至少 1 小时；
3. 网络固定：全程康涅狄格稳定线路，杜绝频繁切换 IP；
4. 重心分配：Swagbucks 优先完成问卷、每日目标；InboxDollars 仅碎片时间少量操作，不猛冲余额。

八、兑换策略 & 长期路线

  • Swagbucks 兑换：积分达标后不要立刻提现，稳定运营一段时间，优先兑换亚马逊电子礼品卡，降低重度 KYC 审核概率。
  • 若拿到第二个美号：号 A → Swagbucks，号 B → InboxDollars，双线稳定解除抢占隐患；若只有 1 个美号，做好长期只深耕一个平台的准备。
  • 后续拥有本人美号，可在账号设置内更换绑定号码，越早换风险越低。

1. Appen（EliteAI 承包商门户）

定位

AI 训练数据众包，项目制，普通项目时薪约 $3–9，高难 / 专业项目更高；你截图所见的"设置用户名"页即其 EliteAI 注册流程。

注册步骤

  1. 访问 Appen 官网 → 进入承包商 / EliteAI 注册入口；
  2. 邮箱注册：用 你的 Outlook 邮箱（示例：you@example.com）；
  3. 设置用户名 → 填 你的 Appen 用户名（规则：4–16 位、仅小写字母 + 数字、不得含 eliteai / admin / appen、非纯数字、填后不可改）；
  4. 填个人资料：国家 = United States，语言 = 中文（母语）/ English（流利），技能 = IT / Project Management / 数据标注；
  5. 完成入门测评 / 培训项目，攒平台信誉；
  6. 绑定 PayPal 收款（姓名与证件一致）。

避坑

  • 用户名不可改，确认大小写拼写再提交；
  • 部分项目签 NDA，注意数据保密、不得外传任务内容；
  • 先做小额入门项目建立评分，再接高价项目。

注册步骤

  1. 访问 outlier.ai → 邮箱注册（建议 你的 Outlook 邮箱（示例：you@example.com））；
  2. 填写教育与专业背景；
  3. 通过技能筛选（如写作 / 编程 / 学科测试）；
  4. 接任务，按周结算。

用户名建议

用 你的 Appen 用户名 或 liujunping，与 Appen 统一、降低记忆负担（后台平台无需品牌化）。

避坑

  • 警惕仿冒站，只认 outlier.ai 官方域名；
  • 项目量波动大，勿当成稳定工资；

3. Upwork（自由职业 · 公开接单）

定位

项目制 IT / PM 服务，时薪约 $30–100+，是你专业变现的主战场（AI 项目管理咨询 / 企业培训设计 / AI 落地辅导）。

注册步骤

  1. 访问 upwork.com → 邮箱注册（你的 Outlook 邮箱（示例：you@example.com））；
  2. 设置 Profile 显示名 → 你的 Upwork / Fiverr 公开显示名（品牌）或 你的护照姓名（拼音）（真实，更显专业可信）；
  3. 写 Title，例如 AI Project Management Consultant | PMP-certified；
  4. 填技能、时薪、工作经历（突出 20 年培训 + IT / PM）；
  5. 完成身份 ID 验证（须与证件一致）；
  6. 用 Connects 投提案接单。

避坑

  • 先小额接单攒 5★ 好评，再涨薪；
  • Connects 谨慎花，别广撒网；
  • 任何"站外付款 / 预付定金"都是诈骗，只走 Upwork 托管。

4. Fiverr（服务商品 gigs）

五、新人避雷 & 首月节奏

graph TD A[第1周：完善Profile+发3个Gig+投10单] --> B[第2-3周：首单交付·换5星好评] B --> C[第4周起：时薪$35→$50·减少低质投递] C --> D[第2个月：好评≥5后提到$60-90·只接匹配单]

新手必记 5 条

  • Connects 是资源：新人每投约耗 8–12 个 Connects，前 10 单只投「高度匹配 + 预算合理」的 job，别广撒网。
  • 前 5 单压价换好评：宁可接受 Basic 档低价，也要把交付质量拉满，好评是涨价的门票。
  • 英语靠写不靠说：Upwork 以文字沟通为主，你读写够用；视频会议如需要，可提前准备提纲。
  • 每周登录 ≥ 3 次：保持「Available」状态，算法才会推你的 Profile。
  • 任何「先给你打钱/先付费/代写」一律拉黑举报：正规客户不会这么操作。
